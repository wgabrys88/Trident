# One-shot: chatterbox.exe file.txt speaks chatterbox.text and exits.
# Resident: chatterbox.exe --resident file.txt loads this file once and stays up.
# The resident reads mouth.prompt.txt and writes the wav name to mouth.response.txt.
# mouth.py starts and reuses that process. A bare file argument stays one-shot.
# The values below are used as written. Nothing in the program replaces them.
# Each phrase writes HH-MM-SS-mmm_chatterbox_out_NNN.txt in the current directory.
# NNN starts at 000. An existing name is kept and the next number is used.
# Paths are names in this file's directory. A value ending in << runs until a line that is only <<.
# chatterbox.text is spoken as written in one-shot mode. Resident mode ignores it and speaks each prompt.
# chatterbox.language is passed to the model file as written. The resident keeps that language until restart.

nano.t3 nano-t3.gguf
nano.s3 nano-s3.gguf
v3.t3 v3-t3.gguf
v3.s3 v3-s3.gguf

# Chatterbox. chatterbox.exe. One-shot speaks chatterbox.text. The resident speaks each mouth.prompt.txt.
# chatterbox.language must be a tag stored in that GGUF. The text is not rewritten into English.
chatterbox.variant nano
chatterbox.language en
chatterbox.sample-rate 24000
chatterbox.graph-nodes 8192
chatterbox.end-trim-samples 960
chatterbox.gpu 0
chatterbox.seed 42
chatterbox.temperature 0.8
chatterbox.repeat-penalty 1.2
chatterbox.n-predict 1000
chatterbox.trim-fade-samples 480
chatterbox.top-p 0.95
chatterbox.cfm-steps 2
chatterbox.top-k 1000
chatterbox.min-p 0.05
chatterbox.cfg-weight 0.5
chatterbox.exaggeration 0.5
chatterbox.cfm-cfg 0.7
chatterbox.play on
chatterbox.text <<
Say one short sentence.
<<
