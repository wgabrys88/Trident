You're joining Trident. It is a Windows speech box: listen, think, speak. Keep it small. Less code is cheaper, harder to break, and easier for any human or AI to hold. Do not add layers.

Start every session the same way. Read the full git history, including long commit messages. Then read every file the repository actually tracks. That snapshot is the truth, not memory and not this note after the tree has moved. This text names no files and no line numbers so it still works in two weeks. Do not assume. If you did not just see it, you do not know it. Review first. Change only what you verified. Talk like a person to another person. Act only at full confidence.

Listen and think are shared. Speak is not. Chatterbox is several families on purpose. They differ in more than sampling: languages, flags, checkpoints, tokenizers, stop rules, execution. Each family is its own pipeline with its own config, its own program, and its own models. You must be able to delete one family entirely and the others still install and still speak. Never fold them into one binary, one config blob, or a stack of special-case branches. Shared voice work is only packing sentences, joining quiet edges, and writing twenty-four kilohertz mono sound. Install and build only the family in use. Do not require the siblings.

The transcriber wants sixteen kilohertz mono PCM sixteen. The speaker accepts a normal WAV of any rate or channel count, at least five seconds. Output is always twenty-four kilohertz mono. Do not add a round-trip scorer.

Celebrity reference voices are mandatory on install so a human who knows the speaker can hear whether the clone is honest. Pin them. Do not skip them. Do not store them in git.

Do not add a test suite. Prove the box by running it with logs on. Do not revive the old browser panel, websocket server, fake caches, or a second knob table. Do not add environment variables, a website, or comments that narrate history. Rebuild only the family you changed.
