# Trident

Trident is one organism. Luna decides. Python only carries out the tool she chooses.

## Luna

Luna is `gpt-5.6-luna-none` through the Cursor agent CLI. She is in agent mode. Ask mode is not used. Do not pass `--mode ask`.

She reads screenshot PNGs herself. There is no second vision model in this stage.

## The call

A fresh process asks Luna what is actually true, synthesizes that sentence to audio, then rings Wojciech. He hears it as soon as he answers. The sentence is not stored in code. He may answer or not. If he does not, the organism continues.

She calls again when she is confused or the work is finished, again in words taken from the real state. Wojciech is the consultant above the machine.

## The task

His words are the task. Winning a chess game with white, then sketching a cat in Microsoft Paint, is one example of a task. It is not special code. She chooses tools by what the words mean. She hangs up when he asks, or when she is done with the call.

## consult

`consult` is how Trident changes itself. It spawns another Luna in agent mode. That Luna reads this file and rewrites the tree: add, change, or delete tools and code. Then the process restarts and continues the task. Ask mode is not used. This is the self-heal, the self-create, and the self-improve. It is not a training phase.

## Journal

Telegram receives the run log. Every PNG and WAV named in a log line is attached. Those are the same files stored in the run.

## Body

Python hears, speaks, calls, captures the screen, and moves the pointer. It does not choose the task or the sentence.
