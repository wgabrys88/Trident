## PROVEN Defect #1 — Algorithmic: `sample_next_token_mtl()` compounds repeat_penalty per occurrence

### Location
`chatterbox.cpp/src/t3_mtl.cpp:1142-1147` (pre-fix)

### Defect
```cpp
if (p.repeat_penalty != 1.0f) {
    for (int32_t t : generated) {   // iterates EVERY occurrence
        if (t < 0 || (size_t) t >= V) continue;
        if (l[t] > 0.0f) l[t] /= p.repeat_penalty;
        else             l[t] *= p.repeat_penalty;
    }
}
```

### Turbo reference (correct)
`chatterbox.cpp/src/main.cpp:560-567`
```cpp
if (params.repeat_penalty != 1.0f && !generated.empty()) {
    std::set<int32_t> seen(generated.begin(), generated.end());
    for (int32_t t : seen) { ... }
}
```

### Mechanism
With `repeat_penalty=1.2`, a phoneme token appearing N times in the generated stream had its logit divided by `1.2^N`. A token appearing 20 times got `~38×` suppression. The Turbo implementation applies exactly `1.2×` once per unique token ID.

### Fix
- Deduplicate via `std::set<int32_t>`
- Match Turbo's order: repeat_penalty before temperature
- Add `<set>` include
- Commits: `1eae6e8` (logic), `aa81669` (include)
- Pinned in `Trident/config.py`: `CHATTERBOX_REV = "aa81669ebdf0471e51babc8bfc33e8eebc8b8cdf"`
