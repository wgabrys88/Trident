The user's framing in plain language: the user should not be able to tell they are talking to a program.

## What "north star" means in practice (proving criteria)

A preserved run directory from the real Pascal (GTX 1060) machine must show, in the journal (not in commentary):

1. **Boot from the pins that are actually in the tree** (Trident SHA + exact Chatterbox SHA pair).
2. **A multi-sentence reply where speech starts overlapping the language model**, not waiting for the full answer (first PCM before `llm.done`).
3. **Barge-in**: old audio stops, native TTS survives the cancel, new-epoch audio is heard, old-epoch audio is not accepted.
4. **The output callback confirms silence after cancel** (not inferred from "queue looks empty").
5. **Playing the assistant with the mic open does not become a user ASR turn** (self-ASR rejection), **but real overlapping human speech is still detected** and cancels the old reply. AEC is only added if a proving run shows that loop is broken.
6. **No extra idle invented by Trident between queued spoken pieces**. Engine time is allowed; an application gap is not.
7. **Ctrl+C tears capture, TTS, the PCM worker, the speaker, and the resident processes down cleanly** without reporting shutdown as barge-in.

Nano first. Turbo and V3 only after Nano passes on the hardware matrix. Pascal first. Iris Xe only after Pascal passes.

## The five architectural invariants the project refuses to break

`c0798ed` and the briefing commit (`c3db3dd`) and the lifelong refusal across the history:

1. **Capture and VAD stay live**. They do not block on ASR.
2. **ASR does not run inside the VAD callback**. A completed acoustic utterance is handed to one conversation worker.
3. **One epoch owns interruption**. Advancing the epoch cancels old playback and old TTS work.
4. **One Speaker owns the output device**. Silence is confirmed by the PortAudio/WASAPI callback, not inferred.
5. **One persistent Chatterbox connection owns native TTS**. No second protocol, no reconnect/retry/fallback path, no compatibility server.
6. **Pieces on the TTS wire carry identity** (epoch / response / piece). Stale PCM after an epoch advance is rejected, not played.
7. **Barge-in is a real event**: the user spoke **and** that speech interrupted work that was actually happening. An epoch bump on shutdown, or an epoch bump with nothing to interrupt, is not barge-in.
8. **Worker failures surface to the main loop**. Run directories are evidence; they are not deleted as cleanup.
9. **Speech is sentences, not character quotas**. The segmenter should emit a sentence when punctuation closes it. The 8-word soft floor + 60-word/480-char hard cap is a safety net when the model never punctuates, not the product.
10. **Sampling belongs to the owner of the model**. TTS knobs match `engine.h` canonical defaults. Gemma sampling matches current Gemma 4 guidance. No shadow profile in Trident.

## What was deliberately rejected across the history

- Synchronous ASR in VAD
- Deletion of run directories
- A fake Chatterbox client at readiness
- Barge-in as a synonym for epoch
- A second TTS protocol
- Reconnect / retry / fallback TTS
- Speculative AEC
- A compatibility server
- ffmpeg WASAPI
- CABLE-only audio (was a phase, removed in `7b6d1dc`)
- Quantization / CFM-step cuts just to make a latency graph green
- Per-frame PCM/frame journal spam
- Speculative software dependencies (AEC, retries, additional queues)

## The two landmark commits to internalize

### `c0798ed` — "Rebuild conversation ownership around acoustic turns" (the architectural restoration)

This is the commit that defined the ownership invariants. It split ASR out of VAD, made Smart Turn own acoustic completion, made one epoch own interruption, made the Speaker callback-confirmed, made the persistent Chatterbox connection own native TTS, and made Barge-in conditional on real interruption. Every commit since has been either preserving this shape or measuring its gaps.

### `0e3274b` — "acoustic-turn ownership with native streaming TTS" (the streaming restoration)

The Trident half of North Star restoration. Based on `c0798ed`. Adds native streaming wire (`synthesize_pieces_streaming`), sentence-first segmentation, engine.h canonical TTS defaults, and explicitly states the eight acceptance criteria for proving Pascal acceptance, plus the four things deliberately not added.
