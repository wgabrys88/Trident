Exclusive server

Matching contract and WaitNamedPipeW(pipe, 1000) reuses; otherwise kill (taskkill /F /T /PID, wait for exit, unlink), Popen with DETACHED_PROCESS|CREATE_NEW_PROCESS_GROUP|CREATE_NO_WINDOW and DEVNULL stdio, then wait for the pipe; child exit or 30 s timeout raises. Per-request errors inside the server are replied as "error <what>" and raised in the host; the server stays resident.
