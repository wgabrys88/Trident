Goal (the product)
python tts.py nano|turbo|v3 [flags] TEXT [language] downloads checkpoints, converts GGUF, bakes a voice, reuses or starts one detached named-pipe Vulkan server, writes one 24 kHz mono WAV in the repo root, prints its path. At most one chatterbox-server.exe on the machine. Same command+voice contract reuses VRAM; any other contract kills the live server then starts the new one. nano/turbo = GPT-2 meanflow; v3 = Llama CFG, multilingual: the positional language is a real user flag, validated against the language-token inventory recorded in the T3 GGUF, passed to the MTL tokenizer child. Exclusive server, one flag table, removable JSON quant, and GGUF-owned model facts are the product. Minimal code that is fully operational with every control; when the checklist below is done the project is release-ready and further work is maintenance only.

Architecture (neither CLI nor GGUF, lives once in C++): 15 s GPT-2 / 6 s Llama bake conditioning (selected by T3 general.architecture in bake.cpp); Llama drops its last 960 samples before Audio::fade; Audio::write is 24 kHz; the baker uses VulkanBackend(0). Do not add these as flags or kv.

Quant — separate and removable
scripts/quant.py is Policy(default, rules).add only. TYPES from lowercase GGMLQuantizationType names. Integer tensors stay integer. First conjunctive prefix/suffix/contains/ndim match wins, else default. Everything goes through gguf.quants.quantize; packing errors propagate. No catch, retry, Q4_K_M recipe, imatrix, or CPU dequant. Native Vulkan upload retained; F16 3D conv expansion retained; GgufFile::floats requires F32. Shipped rules: scripts/quant_t3.json (prefixes chatterbox/, voice_encoder/, model/wpe, model/ln_f/, model/norm/, model/rope_freq_factors; suffix /b, /g; ndim 1) and scripts/quant_s3.json (prefixes flow/input_embedding, flow/spk_embed_affine/, s3gen/builtin/, s3gen/mel_fb/, campplus/, s3tokv2/, cfm/, hift/; contains /attn/pos_bias_; suffix /b; ndim 1, 3, 4). CLI type is the default; --t3-quant-policy / --s3-quant-policy replace rules. Names: chatterbox-t3-{variant}-{default}-{sha8}.gguf, chatterbox-s3gen-{family}-{default}-{sha8}.gguf, sha8 = sha256 of canonical rules JSON. quant.py plus the two JSONs are the whole mechanism.

Exclusive server
One models/server.pid holding {pid, contract:{command, voice}}; command is exe, voice t3, voice s3, pipe name, then every server flag pair. Leftover models/*.pid are killed and removed. Matching contract and WaitNamedPipeW(pipe, 1000) reuses; otherwise kill (taskkill /F /T /PID, wait for exit, unlink), Popen with DETACHED_PROCESS|CREATE_NEW_PROCESS_GROUP|CREATE_NO_WINDOW and DEVNULL stdio, then wait for the pipe; child exit or 30 s timeout raises. EngineBuild and VoiceBake kill server.pid before replacing locked files. No host TerminateProcess, no atexit, no kill when tts.py exits. The Llama tokenizer child TerminateProcess in MtlTokenizer::~MtlTokenizer is unrelated and stays. Per-request errors inside the server are replied as "error <what>" and raised in the host; the server stays resident.
