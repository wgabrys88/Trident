State right now:

  - Audio flow: mic -> Capture (gated Silero) -> ASR -> Conversation
    LLM stream -> SpeechSegmenter -> TTS worker -> resident -> speaker.
    One speak path, one TTS client per turn.
  - Epoch + drop: `audio_epoch` advances on VAD start, PTT cut,
    manual submit, VAD reconfigure, stop. Every audio-pcm event
    carries its epoch. Both the agent pump and the Gradio pump drop
    stale PCM.
  - TTS wire: client sends {u32 piece_index, u32 path_len,
    u32 text_len, text, path} per piece. piece_index=0xFFFFFFFF ends,
    0xFFFFFFFE cancels. Server sends {u32 kind, u32 bytes}: kind=2
    is PCM int16, kind=3 is piece-done, kind=0 is metrics, kind=1
    is error. First path is the WAV; later paths ignored.
  - Session::synthesize_stream routes through the pin's
    Engine::synthesize(text, on_chunk) when
    runtime.stream_chunk_tokens > 0, otherwise per-piece blocking
    synth. T3-with-S3Gen overlap within a piece uses the pin's
    streaming T3 path. Cross-piece T3-of-N+1 with S3Gen-of-N is
    NOT exposed by this pin; the per-piece worker is the limit and
    is documented as such in the commit.
  - Session::request_cancel calls Engine::cancel(). The pin
    re-clears the flag on the next synthesize (line 583 of pin).
  - Echo reject: Capture keeps a TTS_RATE int16 ring of the last
    ECHO_RING_MS=1500 ms of speaker PCM. On VAD start, the last
    200 ms of the mic frame is correlated against the ring; if
    corr >= 0.7 and ring_std >= 200 the VAD is suppressed.
  - save_clone (UI) returns (status_text, dropdown, slug) without
    raising. CLI save_voice remains strict.
  - Gradio: conversation_pump drops stale events and yields a fresh
    gr.Audio(value=None, streaming=True, autoplay=True) on
    audio-reset to remount the player. The agent's Speaker.reset()
    does the real hard stop via PortAudio abort.
