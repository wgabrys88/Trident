Distance to north star: about 70 percent.

What the system can do today: the user can talk over the machine,
the assistant stops mid-word, the new reply is heard, the first
piece of audio starts while the language model is still writing,
and the assistant does not hear its own voice as a user turn. This
was proven on the real Windows rig with a 120 second long-form test
where the assistant handled ten user turns in real time with zero
microphone overflow and zero stale audio leaks.

What the system cannot do yet: the language model still answers
each fragment of a long user utterance as if it were a complete
question, because the voice activity detector is allowed to split
one sentence into many small turns. The echo rejection is wired but
was not exercised on a speaker that bleeds into the microphone. The
T3 text-to-speech stage still waits for the previous S3Gen audio
stage to finish before starting the next piece, because the
chatterbox library does not expose a session-level T3 stream. Long
term memory between sessions is not started.

The next move: boot residents in turbo family in English and read a
short text aloud through the new TTS wire to prove the streaming
speak path on the real speakers. Then drive the Gradio UI to prove
the barge in with echo rejection through open speakers. Then start
the long term memory work, which is the next big theme.
