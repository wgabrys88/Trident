What shipped in the most recent commit:

  agent.py, config.py, conversation.py, local_api.py, main.py,
  tts/include/{audio,cli,session}.hpp, tts/src/{cli,server,session}.cpp,
  ui.py
    - Audio flow is now: mic -> Capture (gated Silero) -> ASR ->
      Conversation LLM stream -> SpeechSegmenter -> TTS worker ->
      resident -> speaker. One speak path, one TTS client per turn.
    - Epoch + drop. `audio_epoch` advances on VAD start, PTT cut,
      manual submit, VAD reconfigure, stop. Every audio-pcm event
      carries its epoch. Both the agent pump and the Gradio pump
      drop stale PCM.
    - TTS resident wire changed to
      {u32 piece_index, u32 path_len, u32 text_len, text, path}
      with 0xFFFFFFFF as the end sentinel and 0xFFFFFFFE for cancel.
      Frames: {u32 kind, u32 bytes}. kind=2 is PCM int16, kind=3
      is piece-done, kind=0 is metrics, kind=1 is error.
    - Session::synthesize_stream routes through the pin's
      `Engine::synthesize(text, on_chunk)` when
      `runtime.stream_chunk_tokens > 0`, otherwise falls back to
      per-piece blocking synth (first-PCM-during-Gemma still ships).
    - Session::request_cancel() calls `Engine::cancel()` (the pin
      re-clears the flag on the next synthesize).
    - TTS worker holds a single socket per turn, sends pieces as the
      segmenter yields them, drains PCM, checks `audio_epoch` before
      each emit, calls `Engine::cancel()` via `cancel_piece()` on
      interrupt, closes the socket on sentinel or turn change.
    - Echo reject: `Capture` keeps a TTS_RATE int16 ring of the last
      1.5 s of speaker PCM (ECHO_RING_MS). On VAD start, the last
      200 ms of the mic frame is correlated against the ring; if
      corr >= 0.7 and ring_std >= 200 the VAD is suppressed.
    - `save_clone` returns status text on success, missing audio,
      empty name, or invalid path; no traceback. The CLI
      `save_voice` remains strict.
    - Gradio: `conversation_pump` drops stale events and yields
      `gr.Audio(value=None, streaming=True, autoplay=True)` on
      audio-reset to remount the player. The agent's speaker
      `reset()` does the real hard stop via PortAudio abort.
    - The legacy `cancelled_through` skip-as-control is gone.
    - Live ASR tab is left as file-only this session (per user
      direction). Implementation deferred.
