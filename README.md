You are picking up Trident with no prior chat. This note is the memory.

Trident is a Windows x64 speech box: listen with Parakeet, think with Gemma on llama.cpp Vulkan, speak with Chatterbox. Git holds the Python host, the three family TTS wrappers, the chatterbox patches, the default English reference clip, and this file. It does not hold binaries, GGUFs, wav dumps, venvs, or the cloned chatterbox tree. A new machine is supposed to grow all of that from `python main.py install`.

The box this was tuned on is a GTX 1060 6GB, Pascal, compute 6.1. Vulkan will tell you fp16 is off, bf16 is off, warp is 32, and there are no matrix cores. Believe it. An f16 GGUF on this card is a file format, not a fast path. Math is fp32. Do not try to “turn fp16 on.” Do not assume flash-attn tensor cores exist. If T3 silently lands on CPU you will see it in the log as a fallback line; treat that as a failed run, not a slow one.

Clone, then install the family you care about. v3 is the multilingual one. turbo and nano are English-only and frozen for comparison, not for tinkering. Install clones pinned chatterbox and ggml, applies every patch in the patches folder in name order, builds three TTS programs, and fetches or converts models. A tree with no family binaries compiles. A tree that already has them skips the compile and only fetches missing models. There is no hash, no stamp, no extra check. If you change a patch or a wrapper after binaries exist, delete the TTS runtime folder (and the chatterbox build if you want a clean library) so install actually rebuilds. Do not run a leftover unified TTS binary if you find one; the three family names are the real programs.

The daily smoke is probe, one English sentence, not a two-minute passage. It writes UTF-8 without a BOM, runs v3, and fails if Vulkan did not take the model, if the reference voice was not baked, if English encode is not start-text then the English language id then the words then stop-text, or if T3 hit the token cap instead of EOS. That is the one-token / one-sentence test. Do that first. Stretch to a paragraph only after the sentence looks like speech. A long calibration passage is a graduation exam, not a morning habit. Do not bring Parakeet back as a WER oracle. It already lied about German. Listen with duration, speech density, gap count, clipping, and a seconds-axis energy plot if you need a plot at all.

Read the stderr story. Every family binary prints `tts` lines from the text file to the last sample. A healthy English v3 probe shows: no BOM, family v3, the 1060 Vulkan banner with fp16 off, backend Vulkan, multilingual T3, voice overridden from your reference, encode ids starting 255 then 708, T3 stopping on EOS with cap 0, then a wav. Poison in that log is a BOM (PowerShell UTF-8 files used to inject UNK), CPU fallback, a reference that was ignored, wrong language ids, or cap 1 which usually means looping. Gemma is no longer muted: verbosity 0, timings, perf, prefixes and timestamps. Do not turn llama.cpp all the way to verbose-infinity unless you want tensor spam. The brain path uses llama-cli, not the server binary, though the same log flags exist there.

v3 English is not mastered. We made the tokenizer honest and the logs honest. We did not make the voice better. Official start/stop text padding plus official top_p 1.0 and top_k off made a long English read worse than the old illegal combo that still had top_k 1000 and no pad: more seconds, more holes, more clipping. A one-sentence English run today: nano is dense and short; v3 at official top_p is longer and gappier; v3 at 0.95 is a little less gappy and still not shipped. Three sentences of v3 still ran about one and a half times nano and slammed the peak. cfg_weight 0, the official cross-language trick, looped German toward six minutes. Do not use it on long text. Do not open German or Polish until English-on-English is boring. The bundled reference is a usable English clip, not a proven best clone source. Resemble wants roughly ten seconds of clean speech matching the language tag. Official multilingual generate is temperature 0.8, repeat 1.2, min_p 0.05, top_p 1.0, no top_k, cfg 0.5, exaggeration 0.5. We ship exaggeration 0.3 and cfm 7. v3 forces top_k 0. max tokens 768 is a cap, not a target. Passing two CFM steps on v3 does not do two steps; the non-meanflow path clamps low step counts back up.

The converter still copies v3 weights onto v2 filenames. That is intentional. If English is garbage, dump GGUF metadata before you twiddle temperature: you want multilingual T3, the grapheme tokenizer inside the file, start text 255, stop text 0, speech start/stop around 6561/6562, llama 520M. Language ids: English 708, German 636, Polish 717. Token 1 at the front is UNK from a BOM. NFKD lowercase is what Python does; do not “fix” it.

Work like a mixture of experts. Tokenizer person prints ids before anyone believes audio. Vulkan person confirms the GPU actually ran. GGUF person checks metadata before sampling. Sampling person changes one knob at a time. Audio person looks at duration and holes, not a single WER. They argue. You ship what survives.

Do not change packing, glue, and sampling in the same breath. Quiet-edge glue can bite soft onsets at joins, but the ugly hole we saw on three sentences was inside a chunk, which is T3 rambling, not glue. Engine defaults in the library still look like turbo. The v3 wrapper papers over that. turbo and nano wrappers are almost the same program twice; isolation of the flag allowlist is the point, not two copies of main. Policy for language, cfg, and exaggeration should live in the family table, not a filename check. If you edit chatterbox sources by hand and skip updating the matching patch, the next install reset will wipe you.

Poison: Parakeet as the score, a long passage as the first run of the day, grid-searching turbo and nano while you are “there,” PowerShell UTF-8, reconverting GGUF with the wrong revision or skipping the v3-to-v2 copy, pretending f16 means f16 compute on a 1060, cfg 0 on long text, and calling a gappier longer wav “more expressive.”

Install, probe, then the full listen-think-speak path. Master English on this Pascal card first. German and Polish wait.
