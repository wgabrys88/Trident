# Trident

Trident is a living program. `main.py` is the mind, the eye, the watch and the tools. `win32.py` is the hand. `story.txt` and `ledger.md` are the memory. A file `skills/NAME.py` defining `NAME(engine, *args)` becomes the tool `--NAME`.

The brain is Grok through the Cursor CLI. The default is `grok-4.7-medium-fast`. `TRIDENT_MODEL` overrides it. A `grok-4.7` slug named in the sentence wins. Each wake spawns a new agent and does not pass `--resume` or `--continue`.

Retina (Fara) is the only image-recognition tool. Jev (`typesafe/jev-1.14` on OpenRouter) answers typed decisions. The pixel watch writes `scan.json` and does not stop the hand.

```
.\.venv\Scripts\python.exe .\main.py --work . --mind "SENTENCE" 45
```
