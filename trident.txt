# Trident settings. python install.py and the executables read this file and take no arguments.
# Five programs: vad.exe, ear.exe, sense.exe, gemma-brain.exe, chatterbox.exe.
# Each model reads one text file and writes one text file. The file is the whole prompt.
# An image, if present, is a data:image/...;base64, payload inside that prompt.
# Gemma 4 E2B-it sampling is temp 1.0, top-p 0.95, top-k 64.
# Iris: gemma.flash-attn off and f16 KV. Lowering gemma.temp empties <|think|> turns.
# This file sits next to the executables. Paths in it are names in that same directory. Booleans are on or off. A missing required key exits.
# A value ending in << runs until a line that is only <<.
# Deliverables land next to this file. Clones, cmake trees, and checkpoints stay under .install.
# Text is UTF-8. A leading BOM is ignored. Polish and the other languages pass through as UTF-8.
# install.vulkan_sdk empty uses the newest C:\VulkanSDK. install.msvc_arch empty detects this CPU.
# Clearing install.llama_rev tracks llama.cpp master. Clearing install.nemo_rev keeps the cloned revision.
# install.ear_vcpkg_root and install.ear_vcpkg_triplet empty skip vcpkg.
# gemma.tensor-split, gemma.cpu-mask, and gemma.cpu-mask-batch may be empty.
# gemma.threads 0 and gemma.threads-batch 0 use the host thread count.
# bake.cond-seconds -1 uses 15 seconds for nano and turbo, and 6 seconds for v3.
